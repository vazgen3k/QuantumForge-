## Используемая база знаний

В качестве базы знаний используется локальная искусственно изменённая база по вселенной произведений «Дюна».

Исходные тексты были взяты из русскоязычных материалов по вселенной «Дюна», после чего ключевые термины, имена персонажей, названия планет, домов, организаций, технологий и событий были заменены на вымышленные значения.

Примеры замен:

- `Арракис` → `Грецкис`
- `Пол Атрейдес` → `Вазген Калантарян`
- `Фремен` → `Аксакал`
- `Дюна` → `Айсберг`
- `Бене Гессерит` → `Злые бабки`
- `Харконнен` → `Хмурконян`


В FAISS-индекс было добавлено 75 чанков.
Генерация эмбеддингов заняла 0.53 секунд.
